# 카카오뱅크 통신 서비스 프로토타입 (모바일웹)

카카오뱅크 × 핀다이렉트 협력 모델 검토용 요금제 페이지 프로토타입입니다. `index.html` 하나로 동작하며, 폰트·룩앤필은 카카오멤버십 요금제 페이지와 동일한 토큰(카카오 옐로우 / 카카오 브라운 / Pretendard)을 사용합니다.

## 구성

- **상단 배너(자동 순환)**: 두 가지 요금 스킴을 훅 메시지와 함께 하나씩 보여줍니다. 26주 배너에는 카카오프렌즈 26주적금 일러스트, 세이프박스 배너에는 세이프박스 애니메이션(`assets/safebox.mp4`)을 넣었습니다.
  - 26주 통신비 챌린지 — "26주를 완주하면 통신비가 0원"
  - 세이프박스 이자로 내는 통신비 — "387만원 맡기면 통신비 평생 0원"
- **요금제 고르기**: 스킴 탭 → 요금제 카드 선택 → 선택 요금제의 상세 계산표
- **하단 고정 CTA**: 선택한 스킴·요금제를 표시하는 가입하기 버튼

## 요금 스킴

### 26주 통신비 챌린지 (26주적금 결합)

`n개월차 요금 = 기준가 × (7 − n) ÷ 3` — 매월 기준가의 1/3씩 인하, 7개월차(적금 만기월) 0원. 7개월 총액은 7개월 할인 스킴과 동일.

| 요금제 | 기준가 | 1개월차 | … | 7개월차 | 7개월 총액 |
|---|---:|---:|---|---:|---:|
| 5G 5GB/100분_M | 4,900 | 9,800 | | 0 | 34,300 |
| 5G 5GB+ | 3,900 | 7,800 | | 0 | 27,300 |
| 5G 30GB+_M | 9,900 | 19,800 | | 0 | 69,300 |
| 5G 110GB +5Mbps | 12,000 | 24,000 | | 0 | 84,000 |

### 세이프박스 with 핀다이렉트 (연 1.8% 기준으로 현행화)

`필요 예치금 = 월요금 × 12 ÷ 연이율` — 연 1.8%(세전), 이자소득세 15.4% 가정. 세전 약 667배, 세후 약 788배. 권장 예치금은 1만원 단위 올림.

| 요금제 | 판매가(월) | 필요 예치금(세전) | 필요 예치금(세후) | 권장 예치금 | 월 이자(세후) |
|---|---:|---:|---:|---:|---:|
| 5G 5GB/100분_M | 4,900 | 3,266,667 | 3,861,308 | 3,870,000 | 4,911 |
| 5G 5GB+ | 7,900 | 5,266,667 | 6,225,374 | 6,230,000 | 7,906 |
| 5G 30GB+_M | 16,900 | 11,266,667 | 13,317,573 | 13,320,000 | 16,903 |
| 5G 50GB+_M | 23,900 | 15,933,333 | 18,833,727 | 18,840,000 | 23,908 |
| 5G 110GB +5Mbps | 39,900 | 26,600,000 | 31,442,080 | 31,450,000 | 39,910 |

모든 요금제가 세이프박스 한도 1억원 이내입니다. 수치는 페이지 스크립트에서 동일 공식으로 계산됩니다.
